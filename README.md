# Плагин: Ядро ролей клана (Clan Role Manager)

Этот плагин — фундаментальный компонент для управления правами доступа, связанными с кланом, на проектах **MineBlaze, MasedWorld, DexLand и CheatMine**. Он автоматически управляет выдачей и отзывом роли "Member", наделяет администраторов правами и **сохраняет актуальный список членов клана в локальную базу данных**.

Установка этого плагина является обязательной для работы большинства других плагинов, которые взаимодействуют с кланом на указанных серверах.

---

## Основные функции

*   **Автоматическое управление ролями**: Выдает роль `Member` при вступлении в клан и забирает при выходе/кике.
*   **Синхронизация "на лету"**: Если игрок уже состоял в клане до запуска бота, плагин автоматически выдаст ему роль после первого же сообщения в клановый чат.
*   **Сохранение в локальную БД (`PluginStore`)**: Хранит список участников клана через запятую (`nick1, nick2, nick3`). Это позволяет другим плагинам или панели получать актуальный состав клана из базы данных без лишних запросов.
*   **Централизованная система прав**: Создает стандартные права (`member.*`, `member.say`) и группу (`Member`), используемые другими плагинами.
*   **Наделение правами администраторов**: Автоматически добавляет все новые клановые права в системную группу `Admin`.

---

## Хранилище данных (`PluginStore`)

Плагин сохраняет ники участников клана в таблицу `PluginDataStore` под следующим ключом:

*   **Ключ:** `clan_members`
*   **Формат значения:** Строка с никами через запятую (например: `player1, player2, player3`).

### Пример получения списка членов клана из другого плагина:

```javascript
async function onLoad(bot, { store }) {
    // Если нужно прочитать список из хранилища плагина clan-role-manager:
    const membersData = await store.get('clan_members'); 
    // или через REST API / вкладку "Данные" у плагина в панели
    if (membersData) {
        const membersArray = membersData.split(',').map(m => m.trim());
        console.log("Члены клана:", membersArray);
    }
}
